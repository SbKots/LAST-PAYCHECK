# Бесплатный тариф и эксплуатация

Проверено по официальным страницам 6 ноября 2026 года. Никакие платные ресурсы,
карта, Koyeb/Render/Railway или постоянно работающий ПК не требуются для этой архитектуры.

Supabase Free включает 500 МБ БД, 50 000 MAU, 5 ГБ исходящего трафика и 1 ГБ Storage.
Неактивный Free-проект может быть приостановлен через неделю. Доступность нельзя
обещать как у платного SLA; бесплатное практичное решение — локальный Android-кэш
опубликованного каталога и ручное возобновление проекта владельцем при необходимости.
[Тарифы](https://supabase.com/pricing).

Free включает 500 000 вызовов Edge в месяц. Здесь обычные каталоги обходятся без
Edge; одна функция нужна только для серверных интеграций.
[Квота функций](https://supabase.com/docs/guides/functions/pricing).

Лимиты Edge: 256 МБ памяти, 2 с CPU на запрос, 150 с wall-clock на Free.
Три попытки провайдера по 10 с с паузами 1 и 2 с укладываются в wall-clock лимит;
Auth и операции кэша имеют отдельные таймауты. Реальное CPU и потребление памяти
максимального 2-МиБ ответа в hosted Edge runtime ещё нужно измерить.
[Ограничения Edge](https://supabase.com/docs/guides/functions/limits).

Живой сырой кэш ограничен 128 записями, но нужно следить за размером БД, bloat,
числом пользовательских сохранений и egress. Для учебного набора данных разумнее
использовать опубликованные каталоги и редко обновлять внешние источники.
Снижение лимита кэша/частоты обновления — бесплатные варианты при приближении к квоте.
Не добавляйте автоматические keep-alive запросы для обхода паузы Free-проекта.

Встроенная почта Auth рассчитана на ознакомление, имеет строгие ограничения:
официально указано 2 письма/час; доставка по умолчанию ограничена разрешёнными
получателями проекта. Это может помешать массовой регистрации учебной группы.
Для демонстрации подготовить подтверждённые тестовые аккаунты через Dashboard.
Для дальнейшего публичного приложения рассмотреть бесплатный OAuth-провайдер
и проверить его настройки отдельно; платный SMTP автоматически не подключать.
[Auth rate limits](https://supabase.com/docs/guides/auth/rate-limits),
[встроенный SMTP](https://supabase.com/docs/guides/auth/auth-smtp).

Доступность и тарифы O*NET/CarsBase зависят от их собственных правил и ключей.
Они не являются обязательными для загрузки уже опубликованного игрового каталога.
Без доступного бесплатного ключа оставить провайдер отключённым: API вернёт 503,
а игра продолжит использовать DEMO/ранее опубликованные данные. Не выдавать
управляемые тестовые ответы за реальные внешние данные.
